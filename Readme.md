# Travel

## Pages

- Home Page: Hero section, destinations, destination cards, and footer.
- Paraty Page: City information, articles, statistics, gallery, weather, safety, and living costs.

- Responsive Web Design

## Features

- Multi-page website
- Destination exploration
- Image galleries
- City information
- Living cost details
- Responsive design
